# AI Tool Usage & Integrity Disclosure

## Purpose of this document

This statement discloses, specifically and honestly, where and how AI
assistance (Claude, Anthropic) was used in producing this submission
package. It is written to accompany — not replace — an actual AI-detection
scan of the final manuscript text (see "What still needs to happen" below).

## What AI assistance was used for

| Task | AI involvement |
|---|---|
| Experimental design, notebook code, model training, all reported numbers (Tables III–IX, confidence intervals, p-values) | **None.** All experiments were run by the author in their own notebook (`alzheimerupdate_version_1.ipynb`), on their own machine/environment (Table III of the paper), against the author's own dataset copy. |
| Literature search for related work | AI-assisted. Claude was given seven candidate papers (uploaded by the author) and asked to extract citation-relevant content (titles, authors, methods, reported results) to inform the Related Work section and the 20-study comparison table. |
| Prose drafting and editing (Introduction, Related Work, Gaps, Threats to Validity, Conclusion) | AI-assisted. Claude drafted and revised prose based on the author's original manuscript content and the author's verified experimental results; the author is responsible for reviewing and approving all resulting text. |
| LaTeX structuring (architecture section restructuring, new tables, bibliography formatting) | AI-assisted. Claude restructured the existing LaTeX source and added new tables/citations; underlying data and claims were not altered. |
| AI review report (`02_ai_review_report/`) and response to review (`03_response_to_review/`) | **Fully AI-generated**, by explicit design — this is an "AI review" exercise per the assignment rubric, not a claim that a human referee reviewed this paper. |
| Reproducibility package files (`06_reproducibility_package/`) | AI-generated documentation (README, requirements, run instructions), populated with environment details taken directly from the paper's own Table III (not invented). |
| Architecture diagram (Fig. 2, `make_architecture_fig.py`) | AI-generated script producing a schematic diagram from the paper's own stage descriptions — not a plot of experimental results, so it does not encode any data-derived claims. |

## What was NOT AI-generated

- The underlying experiments, the dataset, the notebook's model training and evaluation logic, and every reported quantitative result.
- The original manuscript's core scientific argument and its self-critical documentation of a prior AI-drafted draft's fabricated content (which the author caught and removed before this AI-assisted revision cycle even began).
